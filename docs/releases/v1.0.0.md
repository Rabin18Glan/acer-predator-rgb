# v1.0.0 — First release

Control your Acer Nitro or Predator keyboard lighting from a Linux terminal.

## Features

- Live lighting changes without pressing Apply or Enter.
- Four-zone color selection, including an option to change all zones together.
- Static, Breathing, Neon, Wave, Shifting, and Zoom effects.
- Brightness, animation speed, and direction controls.
- Color presets, RGB sliders, and custom hex colors.
- Keyboard-shaped preview with simulated lighting effects.
- Separate tabs for color selection, effects, speed, and direction.
- Mouse support for tabs, keyboard zones, colors, and sliders.
- `Shift+1–4` shortcuts to select a zone.
- Save and load your lighting settings.
- Command-line options to check driver status, preview commands, or apply saved settings.
- Prebuilt Linux binaries and a one-line installer; no Rust, Cargo, or Python needed to run the app.

## Install

```bash
curl -fsSL https://github.com/Rabin18Glan/acer-predator-rgb/releases/latest/download/install.sh | bash
```

Launch with `acer-predator-rgb`.

## Compatibility

Requires x86_64 Linux, a compatible Acer four-zone RGB keyboard, and the separately
installed [predator_kbd_rgb driver](https://github.com/TomasUribe/predator-rgb).
Tested on Acer Nitro AN515-45.

Individual zone colors work in Static mode. Breathing, Shifting, and Zoom accept
a shared custom color; Wave and Neon generate their own colors. The keyboard
preview is simulated and is not a live readback of the LEDs.
